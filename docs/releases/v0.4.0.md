# StockOrNot v0.4.0 — The full-market MVP

StockOrNot now runs on a real database-backed instrument universe instead of a hardcoded catalog.

## Highlights

- 10,743 active US instruments in Cloudflare D1
- 5,317 common stocks and 5,426 ETFs
- Database-backed rating queue, asset filters, search, leaderboards, validation, and ticker pages
- Repeatable Massive reference-data import with pagination and a versioned migration
- The same focused interface: ticker, full name, and Hot / Not / Skip

## Data scope

This snapshot includes active US-locale instruments classified by Massive as common stock (`CS`) or exchange-traded fund (`ETF`). Other instrument types are intentionally excluded. The catalog is a point-in-time reference-data snapshot and will need scheduled synchronization as listings change.

## Validation

- `npm run lint`
- `npm run build`
- Confirmed 10,743 symbols through the score API
- Confirmed a database-only ticker page and vote submission

StockOrNot remains an entertainment and sentiment-discovery product, not investment research or advice.
