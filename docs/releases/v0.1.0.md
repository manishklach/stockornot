# StockOrNot 0.1.0 — The MVP

The first public source release of **StockOrNot**, a fast crowd-sentiment experience for US stocks and ETFs.

## Highlights

- Vote **Hot**, **Not**, or **Skip** in a rapid, keyboard-friendly rating loop.
- Reveal community sentiment only after voting to reduce anchoring.
- Explore hottest, coldest, and most-divisive leaderboards.
- Filter the rating queue by stocks or ETFs and search the instrument universe.
- Open shareable ticker pages with sentiment summaries and sample trend shapes.
- Keep anonymous votes durable with Cloudflare D1.

## Trust and product safeguards

- One current vote per anonymous device, ticker, and UTC day
- Bound database statements and server-side input validation
- Basic recent-vote velocity protection
- Explicit methodology and financial-product disclaimers
- Illustrative market figures labeled as delayed sample data

## Under the hood

This release uses React 19, TypeScript, Vinext, Vite, Tailwind CSS 4, shadcn UI primitives, Cloudflare Workers, Cloudflare D1, and OpenAI Sites.

The repository includes architecture, development, methodology, roadmap, contribution, security, and changelog documentation.

## What comes next

The next milestone focuses on a production data foundation: licensed US market data, timestamped and adjusted price history, richer sentiment windows, stronger edge abuse controls, and a clean separation between seeded launch totals and organic votes.

> StockOrNot is an entertainment and discovery product—not investment advice, research, or a recommendation to buy or sell securities.
