# StockOrNot 0.3.0 — 100-ticker universe

StockOrNot now offers a much broader local rating queue while keeping the focused ticker-and-name interface.

## Highlights

- Rate 100 unique US-listed instruments: 80 stocks and 20 ETFs.
- Cycle independently through Stocks or ETFs with the existing filter.
- Find any catalog entry through ticker and company-name search.
- Rank the complete universe by hottest, coldest, or most divisive crowd sentiment.
- Open a dedicated sentiment page for every included ticker.

The universe remains deliberately checked into the application for this MVP. A synchronized market-wide instrument database is planned for a later milestone.
